This section will list all of the major changes that happened with the release of **Momentum 5.3.1**. Depending on installation type, all changes may not be applicable

<a name="changelog.5.3.1.table"></a>

| Type | Ticket | Description |
| --- | --- | --- |
| Feature | I-1755 | ESMTP listeners can now advertise the [CHUNKING](/momentum/4/esmtp-listener-extensions#esmtp.listener.extensions.chunking) extension (RFC 3030) and accept `BDAT`, which Microsoft 365, Exchange and Gmail use instead of `DATA` when it is offered. It is off by default; add `CHUNKING` to `SMTP_Extensions` to enable it. Delivery still uses `DATA`, and BINARYMIME is not supported. |
